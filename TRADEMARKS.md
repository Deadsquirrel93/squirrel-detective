# Squirrel Detective Name and Official Distribution

The source code of Squirrel Detective is open source under the MIT license.

However, the official Squirrel Detective project identity is tied to this repository:

- Official repository: https://github.com/Deadsquirrel93/squirrel-detective
- Official releases and updates: GitHub Releases published from this repository

If you modify the project and distribute your own build, you should:

- clearly state that your build is unofficial
- avoid presenting it as the official Squirrel Detective release
- avoid implying endorsement by the original author

This file is intended to make the official distribution channel clear for users.
